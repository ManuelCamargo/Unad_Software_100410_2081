# Software FJ - Fase 4

Proyecto desarrollado en Python para gestionar clientes, servicios y reservas de la empresa Software FJ.

La aplicación utiliza programación orientada a objetos y una interfaz gráfica creada con Tkinter.

## Funcionalidades principales

- Registro de clientes.
- Gestión de servicios.
- Creación y control de reservas.
- Reserva de salas.
- Alquiler de equipos.
- Asesorías especializadas.
- Validaciones y manejo de errores.
- Registro de eventos en archivos de log.
- Cálculo de impuestos y descuentos.
- Datos almacenados en listas, sin base de datos.



La aplicación no utiliza base de datos. La información se maneja mediante objetos y listas durante la ejecución._ Debe tener phyton instalado.
